隱私權政策

最後更新日期：2026 年 10 月 4 日

概述

「Header Override」（以下簡稱「本擴充功能」）尊重並保護使用者的隱私。本隱私權政策說明本擴充功能如何處理您的資料。

資料收集

本擴充功能不會收集或傳輸任何個人資料或使用者資訊，開發者也不會從本擴充功能取得任何資料。

資料儲存

您建立的 header 規則（header 名稱、值、套用網域與開關狀態）僅儲存在瀏覽器本機的擴充功能儲存空間（chrome.storage.local）中，其中可能包含您自行輸入的 API token 等內容。這些資料只存在您的裝置上，不會同步到其他裝置，也不會傳送給開發者或任何第三方。刪除規則或移除本擴充功能即會一併刪除。

資料使用

本擴充功能僅使用您設定的規則，在瀏覽器送往您指定網域的 fetch / XHR 請求上新增、取代或移除 header。header 的修改由 Chrome 內建的 declarativeNetRequest API 執行，本擴充功能不會讀取請求、回應或網頁的內容，也不會記錄您的瀏覽紀錄。

第三方服務

本擴充功能不使用任何第三方分析工具、廣告服務或追蹤技術。

權限說明

  • declarativeNetRequest：用於將您設定的 header 規則套用到送出的請求。
  • storage：用於在您的裝置本機儲存 header 規則與開關設定。
  • 網站存取權限（<all_urls>）：讓規則可以修改您指定的任何網域的 header，包含 localhost 與您自己的伺服器。

政策變更

如本隱私權政策有任何變更，將於本頁面更新。
